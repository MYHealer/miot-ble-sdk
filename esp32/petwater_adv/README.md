# 米家无线智能宠物饮水机（xiaomi.pet_waterer.002）小白版固件 —— ESP32-C3

**一根 Type-C 线、三条命令，串口一条命令就能用。**

烧完这块板子在你的米家里就变成一台「米家无线智能宠物饮水机」：米家 App 能添加它、
设备页能看缺水状态 / 滤芯寿命 / 电量，还能拿它当自动化触发条件（缺水 → 推送）。

- 目标芯片：ESP32-C3（USB-Serial/JTAG 直连）
- 模拟型号：米家无线智能宠物饮水机 `xiaomi.pet_waterer.002`，PID **0x399A**（国区 pdid 14746）
- 上报内容（三槽轮播，一帧一对象）：
  - `0x4843` 缺水（1B bool，0=有水 1=缺水）
  - `0x4C4C` 滤芯寿命（1B uint8，%）
  - `0x5403` 电量（1B uint8，%）
- 通道：MiBeacon V5 加密**广播**（网关收） + 0xFE95 GATT（只用于绑定）

> 只想知道原理不用烧板子：看 [`../t3pro_adv/README.md`](../t3pro_adv/README.md)。
> 本工程与 smoke_adv 骨架相同，只有 PID / 广播对象号 / 轮播槽位不同，代码里都标了 ★。
>
> **2026-11-18 实机验收通过**：米家扫描列表出现「米家无线智能宠物饮水机」→ 添加 3/3 完成
> （did `blt.3.1qtgp3bm84o04`），设备页出现「今日出水次数 / 滤芯滤棉 / 电量 / 感应模式」全功能 UI。
> 三属性云端双向验证：`alarm 1` → `2:1067=true`、`filt 50` → `3:1076=50`、`batt 35` → `5:1003=35`（均 code=0）。

## 一、动手前先看这几行

| 你要做的 | 怎么做 |
|---|---|
| 缺水 正常 / 告警 | 串口发 `alarm 0` / `alarm 1`（或 `toggle` 切换、短按 BOOT） |
| 改滤芯寿命 | 串口发 `filt N`（0~100，%） |
| 改电量 | 串口发 `batt N`（0~100，%） |
| 恢复出厂（重新添加） | 按住 BOOT 5 秒（串口打印「恢复出厂」后自动重启） |
| 看它有没有在干活 | 串口每触发一次都有 `>>> 串口设缺水 / 设滤芯寿命 / 设电量` |

不用接线、不用改代码、不用装别的库。

## 六、★对象号（重点看这段）

新式 spec 设备对象号按公式算，不是 spec piid：

```
eid = 0x4000 | (siid<<10) | (piid-1000)
```

| 属性 | siid.piid | 类型 | 对象号 | 云端 prop |
|---|---|---|---|---|
| 缺水状态 | 2.1067 | bool | `0x4843` | `2:1067` |
| 滤芯寿命 | 3.1076 | uint8 | `0x4C4C` | `3:1076` |
| 电量 | 5.1003 | uint8 | `0x5403` | `5:1003` |

**关键坑**：三个对象**不能同帧发**（帧超过 26B → `miot_beacon_frame_v5_nomac` 返回 `rc=-2`，
广播直接停摆）。本工程用**三槽轮播**——空闲时每 4 秒换一个对象发，事件帧插队时只带刚触发的对象。

**第二个坑**：验证时米家 App 设备页**不能开着**——App 占着 BLE 连接，网关就收不到广播帧，
云端 prop 一直不更新。验证前 `adb shell am force-stop com.xiaomi.smarthome`，保持串口连接读云端。

| 宏 | 含义 |

## 九、常见问题

**扫不到设备？** 物理 MAC 可能已被本账号别的工程绑过 —— 本工程用独立派生 MAC
（`10:00:3B:CE:78:05`），不影响其它工程。扫之前米家 force-stop 重开清缓存。

**云端 prop 一直不更新？** 先确认：① App 设备页已关（见第六节坑2）；② 串口保持连接
（断串口 = DTR/RTS 复位 → 值回默认）；③ 串口日志没有 `加密帧失败 rc=-2`。

**`3:1076` / `5:1003` 读不到？** 轮播约 12 秒一轮，等一轮再读；设值后事件帧会立即插队上报。

## 十、已知边界

- 只模拟广播上报（传感器侧）；真实出水泵/按键联动不在本工程范围。
- 缺水/滤芯/电量是手动触发值，不是真实传感器读数；接真实传感器改 `cli_task` 对应赋值即可。
- 滤芯寿命 `0x4C4C`、电量 `0x5403` 走公式对象号，实测云端 code=0 通过。
