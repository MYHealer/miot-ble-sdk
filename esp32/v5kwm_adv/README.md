# v5kwm_adv —— V5 无线八键开关（ESP32 模拟版）

> **状态：2026-11-14 编译 + 烧录 + 广播实测通过；米家绑定待验。**
> 从 `btn2_adv`（双键 XMWXKG01YL，0x1949）抽出，只有三处差异：PID、键数语义、MAC/NVS。

## 它模拟的是什么

| 项 | 内容 |
|---|---|
| 真品 | **V5 无线八键开关（BLE）**，GranchipIoT（广嵌）方案，电池随意贴 |
| miot-spec | `giot.remote.v58kwm`，产品 ID **16186 = PID `0x3F3A`**，2023-12 发布 |
| 协议 | **普通蓝牙直连（非 Mesh）**——任意蓝牙盲网关即可上云（小爱音箱 Play 增强版实测在官方网关列表：盲网关/蓝牙Mesh1.0/蓝牙） |
| spec | 事件 `5.e.1012` 单击 / `5.e.1013` 双击 / `5.e.1014` 长按（载荷 1B = 键位 1~8）+ 电量 |

与 `btn2_adv` 同一事件模型，只是键位取值从 1/2 扩到 1~8 —— 所以链路风险接近零：
绑定、事件上云、自动化触发都已在 btn2 上验证过一遍。

## 固件怎么用

固件 580,608 B，烧录后启动：

```
I (142) V5KWM: spec table: 2 props (3.1020 btn-config / 3.1003 battery)
I (332) BLE_INIT: Bluetooth MAC: 10:00:3b:ce:72:03
I (382) V5KWM: host synced, MAC 10:00:3B:CE:72:03  bound=0
```

广播（bleak，未绑定态）：

```
svc 70 2a | 3a 3f | 07 | 03 72 ce 3b 00 10 | 11 | 11 10 01 00
            PID=0x3F3A        MAC LSB
mfg 30 20 | 3a 3f | …        ← registered=0x20（米家添加只认这个）
name V5KWM   RSSI −60
```

### 八键模拟（真机 8 个物理键，ESP32 只有一颗 BOOT）

| 动作 | 效果 |
|---|---|
| **单击 BOOT** | K\<n\> 单击（0x4E0C），**键号递增** 1→2→…→8→1 |
| 400ms 内双击 BOOT | K\<n\> 双击（0x4E0D），键号不变 |
| 按住 1~5 秒 | K\<n\> 长按（0x4E0E），键号不变 |
| 按住 ≥5 秒 | 恢复出厂（擦 NVS 重启） |

想测 K5 的双击：先连单击 5 次（串口每次打印 `next click -> K<n> 键<n>`）把键号推进到 5，再双击。

### 添加与使用

1. 米家 → `+` → 添加设备 → 附近设备 → 点 **V5KWM**（预计与 btn2 相同：手机直连 BOND）
2. 绑定后进插件可看到设备操作日志（需网关在线）
3. 小爱音箱 Play 增强版：设备设置里确认「蓝牙网关」已开启
4. 自动化触发条件里选「V5八键开关」的 键n 单击/双击/长按 —— 8 键 × 3 动作 = **24 个触发条件**

## 已知边界

- 八键共用一个「待发槽」：上一事件还没发完（2.5s）时新事件会覆盖它（真机是各键独立队列）
- 键号循环是模拟手段：真机按键是固定的，模拟版靠单击推进键号
- 广播帧里的设备名 `V5KWM` 是占位短名；拿到真机扫一帧后可对齐真名（不影响绑定，米家按 PID 认）
