# occ_adv —— 小米人体存在传感器 小白版

> 状态：2026-11-15 编译 + 烧录 + 启动实测通过；米家绑定待验证。
> 工程 `esp32/occ_adv`，约 620 行，固件 581,296 B，零告警。

## 这是什么

模拟**小米人体存在传感器**（XMOSB01XS，miot 型号 `xiaomi.sensor_occupy.03`，
产品 ID 18051 = PID **`0x4683`**）的 BLE 广播固件。烧进 ESP32-C3 后，
米家 App 把它当一台真存在传感器添加，短按 BOOT 就是「有人 / 无人」切换。

与 `pir2s_adv`（人体传感器 2S）同一套骨架，只换 PID / 对象号 / 按键语义；
两条踩坑经验直接继承：连接期间保持请求配对广播（-28）、电量用标准对象 0x100A。

## 本工程的对象表（由 `xiaomi.sensor_occupy.03` spec 推导）

```text
eid = 0x4000 | (0x200 若是事件) | (siid << 10) | (iid - 1000)
```

| eid | spec | 含义 | 格式 | 发送时机 |
|---|---|---|---|---|
| `0x484E` | 2.p.1078 存在状态 | 0=无人 1=有人 2=快检中 | 1B uint8 | 短按 BOOT / 回无人 / 轮播 |
| `0x4805` | 2.p.1005 光照度 | 环境光照 | 4B float32 lux | 双击 BOOT / 轮播 |
| `0x4852` | 2.p.1082 持续无人 | 自动化「条件」：2 分钟持续无人 | 1B uint8 分 | 轮播 |
| `0x4851` | 2.p.1081 持续有人 | 自动化「条件」：2 分钟持续有人 | 1B uint8 分 | 轮播 |
| `0x100A` | 3.p.1003 电量 | 电量 | 1B uint8 % | 轮播（标准对象，非公式值）|

注：spec 里 `2.e.1028 设备被重置` 和 `5.p.1 BLE 私有参数` v1 不发——
前者只有恢复出厂时才用，后者 piid < 1000 公式不覆盖。

## 操作（板载 BOOT 键）

| 动作 | 效果 |
|---|---|
| 短按 | 存在状态切换：有人(1) ⇄ 无人(0)，连发 3 帧 `0x484E` |
| 双击 | 光照档位切换 5 → 50 → 300 lux（`0x4805`）|
| 长按 ≥5s | 恢复出厂（擦 NVS 重启，可重新添加）|
| 有人 120s 无动作 | 自动回「无人」并推 `0x484E=0` |

## 身份参数

- PID `0x4683` / 名字 `OCCS01`
- NVS 命名空间 `occ`
- 派生 MAC `10:00:3B:CE:74:03`（后缀 `0x74`，避开其他工程）
