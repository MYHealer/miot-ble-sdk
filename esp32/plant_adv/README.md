# 花花草草监测仪（hhcc.plantmonitor.v1 / 0x0098）小白版固件 —— ESP32-C3

**一根 Type-C 线、几条串口命令就能用。**

烧完这块板子在你的米家里就变成一台「花花草草监测仪」：米家 App 能添加它、
绑定植物后设备页显示土壤湿度 / 土壤肥力 / 光照 / 空气温度。

- 目标芯片：ESP32-C3（USB-Serial/JTAG 直连）
- 模拟型号：花花草草监测仪 `hhcc.plantmonitor.v1`，PID **0x0098**
- 上报内容：温度 `0x1004` / 土壤湿度 `0x1008` / 光照 `0x1007`(u24) / 土壤EC `0x1009`
- 通道：MiBeacon V5 加密**广播**（网关收）+ 0xFE95 GATT（只用于绑定）

> 本工程与 `smoke_adv` / `senpres_adv` 骨架相同，只有 PID / 对象号不同。
> 原理见 [`../t3pro_adv/README.md`](../t3pro_adv/README.md)。

---

## 一、动手前先看这几行

| 你要做的 | 怎么做 |
|---|---|
| 空气温度 | 串口 `temp 251`（0.1℃，251=25.1℃） |
| 土壤湿度 % | 串口 `hum 48`（0-100） |
| 光照 lx | 串口 `lux 1234` |
| 土壤肥力 EC | 串口 `ec 1600`（µS/cm） |
| 立刻发某槽事件 | 串口 `fire 0\|1\|2\|3` |
| 恢复出厂 | 按住 BOOT 5 秒（或 `factory`） |

## 三、在米家里添加（含绑定植物）

1. 米家 **+ → 添加设备**（菜单第一项）
2. 发现 **花花草草监测仪** → 点它 → 绑定完成
3. 设备页出现 **绑定植物 → 马上添加** → 植物数据库点 **绿萝** → **完成**
4. 设备页应显示：土壤湿度 / 土壤肥力 / 光照强度 / 空气温度 +「已连接蓝牙网关」

> **坑**：绑定植物**没有跳过按钮**，必须选一株植物（绿萝即可）。
> 验证上云时先 force-stop 米家（设备页占 BLE → 网关收不到广播）。

## 四、对象号（老式标准，不能用 eid 公式）

| UI 项 | 对象号 | 载荷 | 云端 prop |
|---|---|---|---|
| 空气温度 | **0x1004** | int16 0.1℃ | `3:2` |
| 土壤湿度 | **0x1008** | uint8 % | `2:1` |
| 光照强度 | **0x1007** | **uint24** lx | `2:3` |
| 土壤肥力 | **0x1009** | uint16 µS/cm | `2:2` |

**坑**：土壤湿度必须用 `0x1008`，不是空气湿度 `0x1006`（发 0x1006 → 云端 `2:1`
恒 `-704010000`、UI 显示 0）。`0x1007` 必须 `miot_beacon_obj_u24`，写成 4B 整帧错位。

## 六、串口命令

| 命令 | 作用 |
|---|---|
| `temp N` | 温度 0.1℃ 并 fire 槽0 |
| `hum N` | 土壤湿度 % 并 fire 槽1 |
| `lux N` | 光照 lx 并 fire 槽2 |
| `ec N` | 土壤 EC 并 fire 槽3 |
| `fire 0-3` | 只发指定槽事件帧 |
| `info` / `objt/objh/objl/obje` / `factory` | 状态 / 改对象号 / 恢复出厂 |
